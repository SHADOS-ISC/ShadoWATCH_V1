# Changelog

## [0.1.0] - first public release
- Seven-tab dashboard: Overview, IOCs, Actors & malware, Security events, New attacks, Vulnerabilities, Intel reports.
- MISP integration through the REST API (events and IOC attributes), optional GeoIP source map.
- OpenCTI integration through GraphQL (CVEs with EPSS/KEV, reports, sectors, techniques, malware, actors).
- Stale-data banners, defanged IOC display, click-to-copy, search filter, presentation mode.
- Demo mode with fake data (`--demo`), smoke tests and CI.
